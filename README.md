# Diplom-DF2
DF2 Сайт для бронирования столиков в ресторане.

## Установка:
1. Клонировать репозиторий:

```
https://github.com/AleksandrIlin/Diplom-DF2
```

2. Установка зависимостей:

```
poetry install
```

3. Задачи проекта:

```
1. Сверстать сайт для бронирования столиков.
2. Подключить сайт к админке Django.
3. Использовать Bootstrap для создания адаптивного и привлекательного интерфейса.
```

4. Добавление секретных ключей:


```
Заполнить файл .env согласно шаблону .env.example
```


5. Запуск проекта: 

```
python manage.py runserver
```

6. Контейнеризация с Docker

   I. Убедитесь, что у Вас установлен Docker и Docker Compose.

   II. Для сборки и запуска проекта в контейнерах выполните:

```
docker-compose up -d --build
```
